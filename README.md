# 口语六十

一个面向中文母语者的移动端日语日常对话训练应用。每天约 60 分钟，共 8 周、56 天，每天安排一个独立生活场景，目标是旅行与日常生活中的 A2 生存交流，不承诺达到 B1 或母语式流利。

在线地址：<https://maylily1992.github.io/kotoba60-japanese-coach/>

## 已实现

- 七段式 60 分钟课堂：旧句热身、今日对话、词语跟读、三轮角色扮演、语法与注意点、地道用法、完整复盘。
- 8 周完整课程路线和 56 个不同的日常对话场景。
- 每天至少 18 句完整训练材料：6 句场景对话、2 句地道反应、1 句场景语法、6 句系统语法例句、3 句动词实例。
- 16 个循环语法系统模块，覆盖礼貌体时态、动词分类、て形、ない形、ている/てある/ておく、可能、邀请、条件、被动、使役、授受、推量、普通体、助词、目的与引用。
- 每天 3 个动词，每个展示 12 种核心形态：ます、否定、过去、过去否定、て形、た形、ない形、可能形、意志形、ば形、受身形、使役形。
- 每天 6 个词语、1 个核心语法、2 个注意点、2 个地道用法，全部附平假名读音和独立音频。
- 951 条预生成日语语音，统一使用高音、快节奏的元气少年“ハルト”角色声线，不复制具体声优本人的声音。
- 可收藏任意对话、地道表达、语法和动词例句，形成重点句手册，并按复习次数集中巩固。
- 支持实时文字或日语语音输入对谈；配置 OpenAI-compatible 接口后由ハルト即时回应，未配置时继续使用预写场景。
- 整段连续播放、逐句重播、慢速播放、麦克风录音回听和文本记录。
- 自适应规则引擎：根据听懂程度、主观难度、主要卡点、当天精力与历史薄弱项，动态调整提示量、复习顺序和进阶节奏。
- 本地学习进度、连续天数、能力信号与 56 天完成图。
- PWA 支持：部署到 HTTPS 后可添加到手机主屏幕，并离线打开。

## 如何打开

直接打开 `index.html` 可以体验大部分功能。若需要安装到主屏幕，请将整个文件夹部署到静态网站，或在本机通过 HTTP 服务运行。

本机预览示例：

```bash
cd outputs/japanese-speaking-coach
python3 -m http.server 8080
```

电脑访问 `http://localhost:8080`。手机要长期使用，建议部署到 HTTPS 静态托管服务后，再用 Safari（iPhone）的“分享 → 添加到主屏幕”，或 Chrome（Android）的“安装应用”打开。

## 自适应逻辑

应用不把一次朗读或一次测试当成真实能力。它分别记录听力抓取、开口流畅、表达调用、句型准确、节奏发音和交流修复六类信号：

- 难度偏高：减少新内容，保留提示，同一任务重练，未稳定时不机械推进。
- 难度适中：按标准节奏推进，并安排下一次短复习。
- 难度偏低且没有卡点：撤掉提示，加入时间、地点、对象或突发条件。
- 某类卡点持续出现：把该环节前置，只挑一处高价值问题纠正，并验证能否迁移。
- 当天精力偏低：降低认知负荷，先保证完整开口；精力充足：增加脱稿和追问要求。

这些判断是透明的本地规则，不会把“练习掌握度”冒充正式日语等级。麦克风录音只在当前页面内回听，不上传；语音播放依赖设备自带的日语语音。
